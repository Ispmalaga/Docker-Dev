# Docker-Dev
Autoinstalador para debian Docker, Apache, Laravel, PostgreSQL, Next.js, TypeScript y Tailwind CSS

Después de ejecutar el script, puedes iniciar todo el entorno con:

bash
docker-compose up -d
Los servicios estarán disponibles en:

Laravel: http://localhost:8080

Next.js: http://localhost:3000

PostgreSQL: localhost:5432 (usuario: laravel, contraseña: secret, base de datos: laravel)
